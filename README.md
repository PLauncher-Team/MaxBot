# MaxBot

MAX Mini App и backend MAX-бота.

## Требования к серверу

Для развёртывания понадобится:

- VPS с Ubuntu 22.04 или 24.04 и публичным IPv4-адресом.
- Доменное имя с A-записью, указывающей на IPv4-адрес VPS.
- Открытые входящие TCP-порты 80 и 443.
- Установленные Docker Engine и Docker Compose v2.
- Токен MAX-бота.

Перед установкой убедитесь, что DNS-запись домена уже обновилась и домен указывает на IP-адрес VPS.

## Установка

### 1. Установите Git, если он ещё не установлен

```bash
sudo apt update
sudo apt install -y git
```

### 2. Клонируйте репозиторий

```bash
git clone https://github.com/PLauncher-Team/MaxBot.git
cd MaxBot
```

### 3. Запустите установщик

Из корневой папки проекта выполните:

```bash
sudo bash deploy/setup.sh
```

Установщик запросит токен MAX-бота и доменное имя. Вводите домен без `https://` и `http://`, например `mybot.example.com`. Токен будет сохранён на сервере в отдельном файле с ограниченными правами доступа. Установщик соберёт Docker-образы, запустит Nginx, запросит TLS-сертификат Let's Encrypt и запустит приложение.

После успешной установки приложение будет доступно по адресу:

```
https://ваш-домен
```

Для получения сертификата Let's Encrypt домен должен указывать на VPS, а входящий TCP-порт 80 должен быть доступен из интернета.

## Управление

Все команды запускаются из корневой папки проекта (`MaxBot`). Для удобства можно использовать `bash deploy/maxbot <команда>`.

### Проверить состояние контейнеров

```bash
bash deploy/maxbot status
```

Показывает список сервисов Docker Compose и их состояние: запущены ли контейнеры, какие порты опубликованы и есть ли проблемы при запуске.

### Посмотреть логи

```bash
bash deploy/maxbot logs
```

Показывает последние 200 строк логов и продолжает выводить новые в реальном времени. Чтобы выйти из просмотра, нажмите `Ctrl+C`. Контейнеры при этом продолжат работать.

### Перезапустить сервисы

```bash
bash deploy/maxbot restart
```

Перезапускает контейнеры проекта. Используйте, если приложение перестало отвечать или требуется обычный перезапуск. Данные и настройки сохраняются.

### Обновить приложение

```bash
bash deploy/maxbot update
```

Повторно собирает Docker-образы из файлов проекта на сервере и запускает сервисы с обновлёнными образами. Команда сама не загружает изменения из GitHub: перед её запуском нужно обновить файлы проекта до нужной версии. Например:

```bash
git pull
bash deploy/maxbot update
```

### Создать резервную копию данных

```bash
bash deploy/maxbot backup
```

Создаёт архив с содержимым Docker volume, в котором хранятся данные приложения, включая базу SQLite и пользовательские загрузки. Архив сохраняется в папку `backups/` в корне проекта; в имени указывается дата и время создания, например `maxbot-data-20261106-163000.tar.gz`.

Рекомендуется периодически скачивать резервные копии с VPS в отдельное безопасное место. Наличие архива на том же сервере не защищает от потери самого VPS.

### Остановить проект

```bash
bash deploy/maxbot stop
```

Останавливает и удаляет контейнеры проекта и созданную Docker Compose сеть. Данные в именованных Docker volumes сохраняются, поэтому после остановки проект можно снова запустить командами Docker Compose. Эта команда не удаляет резервные копии и файлы проекта.

## Данные и HTTPS

Данные SQLite и загруженные пользователями файлы сохраняются в Docker volume и переживают перезапуск контейнеров. Не удаляйте volumes при обновлении или остановке проекта. Для дополнительной защиты регулярно выполняйте резервное копирование.

Проверка и автоматическое продление сертификата Let's Encrypt настраиваются через systemd timer. Корневой сертификат Минцифры в проекте используется для исходящих HTTPS-запросов к MAX и не является сертификатом HTTPS-сайта.
